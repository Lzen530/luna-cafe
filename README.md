# 루나 카페

React 입문·12주차 카페 실습을 합친 Next.js App Router 프로젝트입니다.

## 실행

Node.js 20.9 이상을 설치하고 압축을 푼 뒤, 이 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 프로덕션 빌드는 `npm run build`로 확인할 수 있습니다.

## 기능

- 메뉴 8개를 커피·음료·디저트로 분류하고 신메뉴와 품절 상태를 표시합니다.
- 카테고리와 메뉴명 검색을 함께 적용하고 결과 개수를 표시합니다.
- 주문 버튼은 페이지 내 시연 주문 메시지를 표시합니다. 품절 메뉴는 주문 버튼이 비활성화됩니다.
- 메뉴별 좋아요가 클릭할 때마다 1씩 늘어나고 검색이나 탭을 전환해도 유지됩니다.
- 스탬프는 최대 10개까지 추가할 수 있으며, 하나씩 취소하거나 초기화할 수 있습니다.
- 주문 안내·좋아요·스탬프는 현재 페이지의 상태로 관리되어 새로고침 시 초기화됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `app/page.js` | 메인 화면과 신메뉴 안내, 메뉴 데이터 전달 |
| `data/menus.js` | 카테고리와 메뉴 데이터 |
| `components/MenuBoard.js` | 검색·탭·시연 주문·좋아요 상태와 메뉴 목록 |
| `components/MenuCard.js` | Props로 재사용하는 메뉴 카드 |
| `components/StampCard.js` | 배열 상태를 사용하는 스탬프 쿠폰 |
| `app/globals.css` | 반응형 화면 스타일 |
